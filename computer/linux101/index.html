Linux 入门

本章主要介绍 Linux 系统的入门基础，包括命令行、文件操作、Shell 基础和环境变量。 熟悉和掌握本章内容后，基本就可以在 Linux/macOS 系统上开展日常研究工作了。

🖥️ 命令行

命令行与图形界面、终端的基本概念。

📁 文件操作

文件系统、文件与目录操作、路径与权限。

🐚 Shell 基础

Shell 扩展、重定向与管道。

⚙️ 环境变量

常见环境变量、PATH 的含义与配置。
