配置操作系统

这一节介绍如何安装和配置常见的操作系统，以满足日常科研工作的需求。对于地震学科研初学者， 通常更推荐使用 Linux 或 macOS；如果日常办公仍然依赖 Windows，则可以通过 WSL 获取 Linux 环境。请根据自己的实际情况选择其中一篇阅读即可；如果已经有一套可用的科研环境，可以跳过本节。

🎩 Fedora 配置指南

适合希望直接把 Linux 作为主力科研系统的读者。

🐧 Ubuntu 配置指南

适合初次接触 Linux、希望先从常见发行版入手的读者。

🍎 macOS 配置指南

适合使用 Mac 作为主力科研设备的读者。

🪟 WSL 配置指南

适合主要使用 Windows、但又需要 Linux 命令行环境的读者。
